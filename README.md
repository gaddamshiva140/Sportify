# 🏏 About the Project

The **Cricket Ground Booking System** is a comprehensive web application that simplifies the process of finding and booking cricket grounds. Players can search nearby grounds, check real-time slot availability, compare prices, and book their preferred time slots with ease. Ground owners can efficiently manage their facilities, bookings, pricing, and availability through a dedicated dashboard.

Built using **React.js** and **Supabase**, the platform provides secure authentication, responsive design, and a seamless booking experience for both players and ground owners.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/cricket-ground-booking.git
```

Navigate to the project

```bash
cd cricket-ground-booking
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Create a production build

```bash
npm run build
```
